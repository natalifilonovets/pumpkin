# Embed the workshop in Genially

Public HTTPS URL: https://natalifilonovets.github.io/pumpkin/

Paste this iframe into Genially’s external embed content field:

```html
<iframe src="https://natalifilonovets.github.io/pumpkin/" title="Frank’s Jack-o’-Lantern Workshop" width="100%" height="720" style="border:0;aspect-ratio:16/9" allow="autoplay; fullscreen; picture-in-picture" allowfullscreen referrerpolicy="strict-origin-when-cross-origin"></iframe>
```

Use a 16:9 area, as large as the slide permits. YouTube needs an internet connection; the Watch on YouTube link remains available if the host blocks playback.
