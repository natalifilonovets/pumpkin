Production game UI sprite atlas on genuine transparent alpha background. Premium polished family Halloween movie workshop prop style, front facing. Dark rich walnut carved wood, sculpted warm aged brass frame following the arrow silhouette, believable deep bevels, tactile grain, small bronze rivets, subtle amber edge light, plum shadows. Each arrow has wide dark EMPTY center for live HTML label BACK or NEXT to be overlaid later. No text or lettering. Match an antique walnut and brass workshop entrance sign. All pixels outside each plaque fully transparent; no scenery, no backdrop gradient, no other objects. Two rows one column, same widths and heights, clear gap between arrows. Aspect ratio approximately 3:2 for the overall two-row sheet.
